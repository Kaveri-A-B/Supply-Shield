# SupplyShield

SupplyShield is a read-only dashboard built around the Olist Brazilian E-Commerce Public Dataset. The Overview summarizes historical delivery outcomes; **Olist orders** lets you search, filter, and export anonymized delivered orders. The application does not mix in synthetic SupplyShield records or MongoDB operational records.

The order history contains derived fields only. Original order, customer, and seller IDs and direct customer/seller details are not included. `OLIST-######` references are generated for display and do not identify records in Olist. Regional labels are coarse aggregates; “late” is an observed historical outcome, not a live alert, predicted probability, or model output.

## Dataset attribution and license

Source: [Brazilian E-Commerce Public Dataset by Olist on Kaggle](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)

License: CC BY-NC-SA 4.0, as stated on the Kaggle dataset card. Use the dataset and derived dashboard data for non-commercial purposes under its terms, preserve attribution, and share adaptations under the same license.

The dashboard includes 96,470 eligible delivered orders from September 2016 through August 2018; 7,826 were delivered after the estimated timestamp. It excludes orders without a valid delivered status and delivery timestamps. It describes completed e-commerce orders and does not provide live freight activity, inventory, returns, carrier events, or operational supplier performance.

## Run locally

Requirements: Node.js 20+ and npm.

```powershell
npm install
npm run dev
```

Open the Vite URL shown in the terminal (normally `http://localhost:5173`). The dashboard loads its bundled derived order history from `client/public/olist_orders.json`; it does not require MongoDB or sign-in.

## Regenerate the derived order file

The original CSV files are excluded from Git. Put the Olist source CSV files in `ml/data/raw/`, then run:

```powershell
node ml/scripts/export_olist_dashboard.mjs
```

The exporter writes the compact, derived dashboard data to `client/public/olist_orders.json` and refuses to write if the eligible-order or late-delivery totals do not match the reviewed dataset (96,470 and 7,826). It omits original order, customer, and seller IDs and direct identifiers.

## Model status

The educational Olist model in the repository is not connected to the dashboard. Its reviewed results were not strong enough to support operational risk predictions. No shipment risk score, disruption prediction, or recommended operational action is generated by this application.

## Build and deployment

```powershell
npm run build
```

The repository includes a Render Blueprint in [`render.yaml`](./render.yaml). The app's current Olist dashboard is static and reads its derived dataset file from the built client assets. Review the Olist license terms before publishing or reusing the dataset, and do not represent these historical records as live shipments.
